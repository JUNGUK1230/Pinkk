# 실행 안전 조건

## 1. 두 단계 실행 스위치

설정에는 의도가 다른 두 스위치가 있습니다.

```yaml
execution:
  execution_enabled: false
  insertion_enabled: false
```

`execution_enabled`는 접근을 포함한 모든 실제 이동 허용 여부입니다.
`insertion_enabled`는 포트 방향 저속 전진을 별도로 허용하는 값입니다.

예를 들어 접근 검증 단계에서는 다음 상태를 사용할 수 있습니다.

```yaml
execution_enabled: true
insertion_enabled: false
```

즉, 포트 전방까지는 이동할 수 있지만 삽입은 허용하지 않습니다.

## 2. TCP 안전 조건

```yaml
tool:
  calibrated: false
```

`require_calibrated_tool=true`일 때 위 값이 false이면 실제 이동을 허용하지 않습니다.
충전기가 단단히 고정되고 `T_flange_plug`를 측정한 뒤에만 true로 변경합니다.

## 3. 검출 안전 조건

이동 명령을 만들기 전에 최소한 다음을 검사합니다.

- 네 특징점이 모두 존재하는가?
- 특징점 좌표가 유한값인가?
- 포트 깊이가 허용 범위 안인가?
- 재투영 오차가 기준 이하인가?
- 검출 결과가 최근 값인가?
- 여러 측정의 위치와 자세 분산이 충분히 작은가?

한 프레임의 YOLO 결과만으로 이동 명령을 보내지 않습니다.

## 4. 이동 안전 조건

- 목표 frame이 예상한 `g_base`인가?
- 목표가 설정된 작업영역 안인가?
- 한 번의 Cartesian 이동량이 제한 이하인가?
- 현재 실행 중인 명령이 없는가?
- 명령 timeout이 지나지 않았는가?
- 로봇 serial을 하나의 프로세스만 열고 있는가?
- 비상정지 방법이 작업자 손에 닿는가?

## 5. 삽입 안전 조건

삽입은 접근보다 별도의 승인이 필요합니다.

- TCP 보정 완료
- IBVS teach pose 저장 완료
- 포트 중심 및 각도 오차가 기준 이하
- 저속 전진 거리 상한 설정
- 전류, 힘 또는 충전 신호 중 최소 하나의 피드백 존재
- 걸림 시 즉시 정지하고 후퇴 가능
- 재시도 횟수 상한 설정

현재 패키지는 위 조건이 준비되지 않았으므로 실제 삽입 백엔드를 포함하지 않습니다.

## 6. 설정 변경 절차

안전 스위치를 true로 바꾸는 것만으로 실제 실행 준비가 끝난 것으로 간주하지
않습니다. 변경 전 다음 결과를 문서화합니다.

1. 좌표 반복성 측정 결과
2. TCP 측정 방법과 값
3. 작업영역 제한
4. 최소 속도 이동 시험 결과
5. 후퇴 시험 결과
6. 비상정지 시험 결과
