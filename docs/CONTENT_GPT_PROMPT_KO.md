# 콘텐츠 작성 GPT에 전달할 요청문

첨부한 ZIP은 PINKK 스마트 주차 프로젝트의 발표 콘텐츠 제작용 자료다.
먼저 `00_READ_ME_FIRST.md`와 `01_DETAILED_PROJECT_BRIEF.md`를 읽고, 필요한 경우
`references`의 원본 근거를 확인하라.

## 요청

한국어 16:9 발표용 PPT 콘텐츠를 10장으로 작성하라. 대상은 대학 프로젝트 발표
청중이며 발표 시간은 약 8~10분이다.

슬라이드 구성:

1. 프로젝트 개요와 핵심 수치
2. 전체 시스템 구조
3. 차량 검출과 주차면 점유 판정
4. namespace 기반 다중 차량 식별
5. 현재 고정 경로의 실제 생성 방식
6. 위치 융합과 MPC
7. Nav2 대신 직접 구성한 기술적 근거
8. 웹 관제와 안전정지
9. 검증 결과와 현재 한계
10. 결론과 다음 단계

각 슬라이드마다 다음을 제공하라.

- 슬라이드 제목
- 화면에 넣을 핵심 문장 1개
- 3~5개의 짧은 bullet
- 사용할 시각 자료 또는 도식 제안
- 30~50초 분량의 발표자 노트

## 작성 규칙

- PPT 화면에 소스 코드, 실행 명령, 긴 ROS 토픽 목록을 넣지 말 것
- 로봇팔과 USB 삽입 내용을 포함하지 말 것
- 자료에 없는 성공률, 오차, 처리속도, FPS를 만들지 말 것
- 자동 차량 식별 로직은 구현됐지만 현재 실차 기본값은 수동 연결임을 구분할 것
- 현재 고정 경로가 Hybrid A* 결과를 그대로 저장한 것이 아님을 명시할 것
- 경로가 실측 기준점, 직선·접선 원호, Bezier, 방향 제한 Reeds–Shepp과 주차
  maneuver를 조합해 생성된다는 점을 설명할 것
- 현재 검증 기준은 26개가 아니라 32개 경로임을 사용할 것
- MPC 전체 회귀에서 전진 재합류 한 항목이 남아 있음을 숨기지 말 것
- 동적 장애물은 회피가 아니라 안전정지로 처리한다고 쓸 것
- Nav2보다 성능이 우수하다고 주장하지 말 것
- Nav2를 사용해도 외부 pose adapter, 전후진 경로 처리, custom MPC, 다중 차량
  coordinator가 필요했고 고정 환경에서는 직접 연결이 더 적합했다는 근거로 설명할 것

## 디자인 방향

- 배경은 흰색 또는 짙은 남색 중 하나로 통일
- 핵심 색상은 경로 이미지와 맞춰 빨간색·자홍색·청록색 사용
- 한 슬라이드당 본문은 최대 6줄 수준
- 시스템 흐름은 좌→우 화살표 도식 사용
- 경로 슬라이드는 ZIP의 `assets` 이미지 사용
- 구현 완료와 현재 한계는 색상 또는 2열 표로 명확히 구분

최종 결과는 먼저 10장 전체 구성표를 제시하고, 이후 슬라이드별 완성 문구와
발표자 노트를 작성하라.
